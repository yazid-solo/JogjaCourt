## SOAL UJIAN

### 1. Pembuatan Video Presentasi Proyek Akhir (Kesesuaian CPMK: CPMK1 dan CPMK2)
Setiap individu wajib membuat video presentasi proyek akhir dengan durasi minimal 30 menit.

**Materi yang Wajib Dipresentasikan:**

**1. Pendahuluan**
*   Latar Belakang
*   Rumusan Masalah
*   Tujuan Pengembangan Sistem
*   Manfaat Sistem

**2. Analisis dan Perancangan Sistem**
*   Deskripsi kebutuhan sistem
*   Use Case atau alur proses bisnis
*   Perancangan arsitektur sistem yang menjelaskan:
    *   Frontend
    *   Backend
    *   Database
    *   Alur komunikasi menggunakan RESTful API

**3. Perancangan Basis Data**
*   Entity Relationship Diagram (ERD)
*   Struktur tabel beserta relasinya
*   Penjelasan fungsi setiap tabel utama

**4. Implementasi Sistem**
*   Penjelasan teknologi/framework yang digunakan
*   Struktur folder proyek
*   Penjelasan fitur-fitur utama yang telah dibuat

**5. Implementasi CRUD**
*   Menunjukkan fitur Create (Tambah Data)
*   Menunjukkan fitur Read (Lihat Data)
*   Menunjukkan fitur Update (Ubah Data)
*   Menunjukkan fitur Delete (Hapus Data)
*   Menjelaskan bagaimana CRUD terhubung dengan database melalui RESTful API.

**6. Demonstrasi (Simulasi) Proyek**
*   Menjalankan aplikasi secara lengkap
*   Demonstrasi seluruh fitur utama
*   Menjelaskan alur penggunaan dari sisi pengguna

**7. Pengujian Responsive Web**
*   Menunjukkan tampilan pada: Desktop, Tablet, Mobile
*   Menjelaskan teknik responsive yang digunakan (misalnya Media Query, Bootstrap, Flexbox, Grid, atau CSS Framework lainnya).

**8. Pengujian RESTful API**
*   Menunjukkan seluruh endpoint API utama menggunakan Postman, Insomnia, atau Swagger. Minimal meliputi:
    *   GET
    *   POST
    *   PUT/PATCH
    *   DELETE
*   Menjelaskan request, response, dan status code yang dihasilkan.

**9. Penjelasan Source Code**
*   Menunjukkan kode backend yang menangani endpoint RESTful API.
*   Menjelaskan proses request hingga response.
*   Menunjukkan kode frontend yang menangani komunikasi dengan API.
*   Menunjukkan kode yang mengimplementasikan responsive web (CSS, Bootstrap, Tailwind, Media Query, atau teknik lainnya).

**10. Laporan Proyek**
Tunjukkan laporan yang telah disusun, minimal berisi:
*   Cover
*   Daftar Isi
*   Pendahuluan
*   Analisis Kebutuhan
*   Perancangan Sistem
*   Implementasi
*   Pengujian
*   Kesimpulan
*   Daftar Pustaka

**11. Penutup**
*   Kendala yang dihadapi selama pengembangan
*   Solusi yang diterapkan
*   Pengembangan sistem yang dapat dilakukan pada masa mendatang

#### Ketentuan Penilaian
Aspek yang akan dinilai meliputi:
*   Kelengkapan fitur aplikasi.
*   Kesesuaian implementasi dengan materi Rekayasa Web.
*   Desain antarmuka (UI/UX).
*   Implementasi responsive web.
*   Implementasi RESTful API.
*   Kualitas struktur database.
*   Kualitas dan kerapian source code.
*   Kemampuan menjelaskan sistem dan source code.
*   Kualitas laporan akhir.

### 2. Pengumpulan Berkas
Seluruh berkas dikumpulkan melalui Edlink paling lambat sesuai jadwal yang telah ditentukan (**01 Agustus 2026**).

**Mahasiswa wajib mengunggah:**
1.  Video presentasi proyek akhir (durasi minimal 30 menit).
2.  Source code Frontend.
3.  Source code Backend.
4.  File database dalam format `.sql`.
5.  Laporan akhir dalam format PDF.
6.  Dokumentasi API dalam format PDF.
7.  File presentasi yang digunakan saat presentasi (PPT atau PDF).

#### Ketentuan Pengumpulan File
Apabila ukuran file terlalu besar, mahasiswa diperbolehkan mengumpulkan dalam bentuk tautan (link) dengan ketentuan sebagai berikut:
*   **Video Presentasi:** menggunakan tautan Google Drive atau YouTube.
*   **Source Code dan Database:** menggunakan tautan GitHub atau Google Drive.

**Catatan:**
*   Pastikan seluruh tautan dapat diakses oleh dosen (tidak bersifat private).
*   Berikan hak akses *"Anyone with the link can view"* untuk Google Drive.
*   Pastikan repository GitHub dapat diakses atau telah diberikan izin apabila menggunakan repository privat.
*   Seluruh file dan tautan harus sudah dapat diakses sebelum batas waktu pengumpulan. Tautan yang tidak dapat dibuka akan dianggap belum mengumpulkan.
